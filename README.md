**Algoritmo em Portugol para aumentar e diminuir o texto com dois botões**

Depois, adicionei dois botões:
um botão chamado "A+" para aumentar a fonte
e outro botão chamado "A-" para diminuir a fonte.

Em seguida, criei uma variável chamada fonte e defini o valor inicial como 16.

Quando o usuário clicar no botão "A+", o algoritmo verifica com IF:
se o botão clicado for "A+", então a fonte aumenta em 2.

ELSE, se o botão clicado for "A-", então a fonte diminui em 2.

Depois disso, o sistema aplica o novo tamanho da fonte no texto.

Assim, sempre que o usuário clicar em "A+"
