**Algoritmo em descrição para aumentar e diminuir o texto com dois botões**

Depois, adicionei dois botões: um botão chamado "A+" para aumentar a fonte e outro botão chamado "A-" para diminuir a fonte.

Em seguida, criei uma variável chamada fonte e defini o valor inicial como 16.

Quando o usuário clicar no botão "A+", o algoritmo verifica com IF: se o botão clicado for "A+", então a fonte aumenta em 2.

ELSE, se o botão clicado for "A-", então a fonte diminui em 2.

Depois disso, o sistema aplica o novo tamanho da fonte no texto.

Assim, sempre que o usuário clicar em "A+"


**Algoritmo em descrição para alterar o constraste com um botão**

Primeiro, inicia o algoritmo e cria uma variável chamada contraste, que começa com valor 0, representando o modo normal.

Depois, é criado um botão de tema escuro na página para que o usuário possa ativar ou desativar o alto contraste.

Quando o usuário clicar no botão tema escuro, o algoritmo verifica a variável usando IF.

Se o valor de tema escuro for igual a 0, significa que o contraste está normal. Então o sistema ativa o tema escuro, mudando as cores da tela, e a variável passa a valer 1.

Caso contrário (ELSE), significa que o alto contraste já está ativado. Então o sistema volta para o contraste normal e a variável volta a valer 0.

Assim, cada vez que o usuário clicar no botão, alterna entre contraste normal e tema escuro.
